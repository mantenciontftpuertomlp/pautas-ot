# Pauta Digital

App para llenar pautas, check list y otros formularios en PDF: marcar actividades, completar datos, anotar observaciones, firmar y enviar por WhatsApp. (Antes se llamaba "Pautas OT".)

- **iPhone / navegador:** https://mantenciontftpuertomlp.github.io/pautas-ot/
  En Safari: Compartir → "Agregar a pantalla de inicio".
- **Android:** [descargar la APK](https://mantenciontftpuertomlp.github.io/pautas-ot/apk/PautasOT_Ver1.33.apk). Desde la Ver. 1.30 la app avisa sola cuando hay una versión nueva.

Versión de prueba (beta), sin fines de lucro. No recopila datos personales: todo queda en el teléfono de cada persona.
Creador: Sebastián Padilla – Mantenedor instrumentista.

Este repositorio contiene solo el código de la app. No subir OT, pautas ni documentos de la empresa.
